How to play

Goal: survive five seasons while balancing profitability, liquidity, competitive performance, fan trust, and long-term asset value.

  1. Set ticket price, roster spending, fan experience, marketing, facility investment, and commercial focus.
  2. Read the projected income statement. Profit is not the same as cash flow.
  3. Lock decisions. A market shock is revealed after you commit.
  4. Repeat for five seasons. Debt above $470M or cash below −$30M triggers financial distress.

Classroom tip: Use the same seed across pods so everyone faces the same shocks. Different strategies can then be compared fairly.
