Same seed + same market + same mandate + same league rule creates the fairest comparison. Common season shocks and common proposal draws are stable even when selection order differs. Different choices still create different exposure.

Capital assets are depreciated over simplified lives. Player signing/program launch costs are expensed. Public support is modeled as a capital contribution with an affordability covenant and 8% less project revenue. Outside equity has no scheduled repayment but dilutes original ownership. Applied extension: DSCR = project operating cash contribution ÷ scheduled debt service. It is not a guaranteed return or a Chapter 4 vocabulary requirement.
