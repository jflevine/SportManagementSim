# Phase 1 — Character + Audio Pass

Implemented for the SPM 343 Build the Ecosystem RPG.

## Visual upgrades
- Replaced abstract in-world character presentation with stylized human figures layered over the existing player/NPC markers.
- Added distinct visual identities for all nine named NPCs.
- Added human dialogue portraits and a humanized sidebar portrait.
- Reworked avatar-color selectors to read as character choices rather than numbered color chips.

## Audio upgrades
- Replaced the original single chiptune loop with an original adaptive Web Audio soundtrack.
- Added district-specific musical moods, synth pads, bass, arpeggiation, percussion, ambience, footsteps, and richer UI/quest/level SFX.
- Audio remains generated locally in the browser; no copyrighted recordings or external audio assets are used.

## Safety / compatibility
- Existing quest logic, save schema, course content, Supabase endpoint, progression, and URLs are unchanged.
- Reduced-motion behavior remains supported.
