# Revenue Jenga — 日本語版

SPM 370 Chapter 3 の「Revenue Jenga」最終版を、日本語話者の学生が同じ授業内で参加できるように翻訳した別バージョンです。

## 設計方針

- 英語版と同じゲームロジック、ショック、採点ロジック、進行順序を使用します。
- 主要な説明・操作・デブリーフを日本語化しています。
- 授業との対応が分かるよう、重要な専門用語の一部は英語も併記しています。
- 英語版の `styles.css` を共有し、視覚デザインは同一に保っています。
